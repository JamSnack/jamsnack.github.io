I have decided to start a Devblog for my current game project "BASEWORLD!"

BASEWORLD! is a 2D sandbox game and is inspired by Terraria and Dig or Die. You'll be exploring procedurally generated worlds, fighting various bosses, looking for epic loot and resources, and upgrading your character and your base. The big catch is that no world is permanent - the Archfiends are seeking to destroy yours one Wave of Creeps at a time. The only way to survive is to build a base and take it to the next world!

Right now I am in a pre-alpha state. I'm working on getting multiplayer set up so that I can finish the singleplayer gameplay loop. Things are getting pretty cool, so stick around to find out what happens next!

I have just completed some "sketchover concepts" for some of the ideas that I need to fleshout. It's not an officail term - just something that I made up, but a sketchover concept is just concept art that is created by sketching over a screenshot of your game. They can be incredibly useful for conceptualizing the actual game content that a developer may need to complete by placing ideas in the world of the game itself.

Below I have prepared a PDF collection of some of the sketchover concepts I created today, as well as some notes that I wrote to remind myself about what I was thinking during each process.



Here you can see that the sketchovers themselves are incredibly simple - that's all that it takes before I start to encounter some important game design questions.

One of the insights I gained from this exercise is that I probably want to create a few different classes of structure ( in the sketchover I identified 5 classes ) - that can each be made out of different materials - instead of one structure object per class of structure per material ( which I probably wouldn't fulfill entirely, and would just pick specific resources for specific functions instead ).
